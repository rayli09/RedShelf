# RedShelf

A work-in-progress native Apple TV client inspired by Rouge's public App Store screenshots. The first milestone is a real, anonymous recommendation feed with a clear error when the upstream site requires sign-in. No account credentials or example content are included.

## Build

Install Xcode and XcodeGen, then run `xcodegen generate` and open `RedShelf.xcodeproj`. Set your own development team and bundle identifier before installing on a device.

The website's unauthenticated feed has not been confirmed to work from the development network. Login, video, search, and personalized content are not implemented yet.
